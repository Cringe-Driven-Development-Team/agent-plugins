# code-review@cdd

Ревью изменений ветки или PR: баги и правила проекта, точность и польза
комментариев, упрощения с сохранением поведения. Один общий навык
`code-review`; неофициальная адаптация инструкций Anthropic для Claude Code и Codex.

Без PR проверяется текущая ветка относительно её базы и локальные staged,
unstaged и относящиеся к задаче untracked файлы; результат приходит в чат.
Явный вызов для конкретного PR **по умолчанию публикует** проверенные замечания
в GitHub отдельными тредами через review типа COMMENT. «Только в чате» отменяет
публикацию. Если права или нужный API недоступны, готовые замечания остаются
в чате с объяснением ограничения.

Проверяемые исходники, индекс, коммиты и ветка не меняются. Допустимы suggestion
blocks, но они не применяются: применение исправлений — отдельная задача.
Навык не делает approve, request changes или merge. Перед публикацией проверяет
актуальный head, существующие треды и результат записи, чтобы не создавать дубли.

## Вызов

Сначала подключите маркетплейс по [корневому README](../../README.md).

Claude Code:

```text
/plugin install code-review@cdd
/code-review:code-review Проверь изменения текущей ветки.
/code-review:code-review Проверь PR https://github.com/ORG/REPO/pull/123.
/code-review:code-review Проверь PR https://github.com/ORG/REPO/pull/123 только в чате.
```

Codex: установите плагин командой `codex plugin add code-review@cdd`, включите
его в доверенном проекте:

```toml
[plugins."code-review@cdd"]
enabled = true
```

Вызовите установленный навык явно в запросе; например:

```text
Используй навык code-review:code-review из code-review@cdd: проверь текущую ветку.
Используй навык code-review:code-review из code-review@cdd: проверь PR https://github.com/ORG/REPO/pull/123.
Используй навык code-review:code-review из code-review@cdd: проверь PR https://github.com/ORG/REPO/pull/123 только в чате.
```

Нужен доступ к проверяемому репозиторию; для PR — доступный GitHub connector/MCP
или `gh` с подходящими правами. Отдельный сервис ревью не требуется. Результаты
[проверки](../../docs/superpowers/verification/2026-11-07-code-review.md) разделяют
поведение навыка и обнаружение установленными клиентами.

## Обновление и лицензия

Исходные файлы и commit закреплены в [PROVENANCE.md](PROVENANCE.md).
Обновления адаптации переносятся вручную с ревью diff; `scripts/sync.sh`
и `upstream.json` её не обслуживают. После обновления marketplace обновите
установленную копию штатным способом клиента из корневого README.
Фиксированная `version` не задаётся: версией служит commit.

Весь этот плагин распространяется под [Apache-2.0](LICENSE).
Источники, изменения и расхождение лицензии в README одного из апстримов
зафиксированы в PROVENANCE; это не официальный плагин Anthropic.
